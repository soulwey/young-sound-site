# YOUNG SOUND — официальный сайт / статическая версия

Премиальный сайт музыкального лейбла Young Sound: главная, услуги, тарифы, кейсы, релизы, отзывы, контакты, информация о конфиденциальности.

Сайт полностью автономен: распакуйте архив и откройте `index.html` в браузере. Файл `render.yaml` содержит конфигурацию для постоянной публикации через Render Blueprint.

## Архитектура и хостинг

Сайт написан на обычных HTML, CSS и JavaScript. **Без сборщика, без зависимостей, без базы данных**. Поэтому его можно положить в отдельный репозиторий GitHub и подключить к Render как **Static Site** (Publish directory: `.`; Build command: `echo ready`). Каждый push будет автоматически выкатываться на сайт.

Рекомендуемые настройки Render:
- service type: `Static Site`
- repo: `soulwey/young-sound-site`
- branch: `main`
- build command: `echo ready`
- publish directory: `.`
- auto deploy: `yes`

## Контент

Редактировать услуги, стартовые пакеты, цены и список кейсов можно в файле [`content.js`](content.js). Навигация, страницы и форма находятся в `app.js`, стили в `styles.css`.

Пакеты — **примеры возможной комплектации**, а не публичная оферта. Цены намеренно указаны «По запросу», поскольку актуальные суммы не подтверждены. Перед изменением публикуемых цен нужно согласовать прайс с владельцем.

## Заявки

Форма не симулирует отправку на сервер: она подготавливает сообщение, копирует его в буфер обмена и открывает личные сообщения менеджера в Telegram. Посетитель должен самостоятельно вставить и отправить сообщение. Для автоматического приёма и хранения заявок потребуется отдельный серверный обработчик или база данных, а также соответствующее уведомление о конфиденциальности.
